Recreate each disabled advisor as a free Claude.ai Project using your Pro subscription.

Why this exists. Five of your six dashboard advisors had no executor tools — they were pure conversational personas burning API tokens for chats your Claude Pro plan already covers free. Maya stays in the dashboard because she has tool access (SQL, mark task done, update workflow map). The other five (Cleo, Ren, Sage, Theo, Vee) are now disabled — paste their prompts into Claude.ai Projects to keep them, without the per-token cost.
  1. Go to claude.ai/projects
  2. Click Create Project
  3. Name it the advisor's name (Cleo, Ren, etc.)
  4. Paste the system prompt below into the Custom instructions field
  5. Repeat for each advisor. Pin the ones you use most to your sidebar.
